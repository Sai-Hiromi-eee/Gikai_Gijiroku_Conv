# 名取市議会 議事録変換ツール

名取市議会の議事録TXTファイルを、[NotebookLM](https://notebooklm.google.com/) や [Obsidian](https://obsidian.md/) で活用しやすいMarkdownファイルに一括変換するJupyterノートブックです。

## ノートブック一覧

| ファイル名 | 対象 |
|-----------|------|
| `Gijiroku_Honkaigi_conv_2026-03-1.ipynb` | 本会議 |
| `Gijiroku_Zaimu_conv_2026-03-1.ipynb` | 財務常任委員会・各分科会 |

## 機能

- 複数TXTファイルの**一括変換**
- cp932（Shift-JIS系）エンコーディングの自動検出
- 出力ファイル名を `日付_会議名.md` 形式に自動変換
- 不要な定型句・ノイズ行の除去（時刻行・罫線・〔〕行など）
- 末尾署名ブロックの自動除去
- 発言者行を `**役職（氏名）**: 発言内容` 形式に変換
- 発言取消（`＿＿+`）を `（発言取消）` に置換
- 令和・平成両対応

### 本会議版の追加機能

- 日程見出し（`日程第〇`）を `##` 見出しに変換
- 折り返し・範囲指定（〜から／〜まで）・補足括弧の連結処理

### 財務常任委員会版の追加機能

- 議案見出し（`議案第〇号`）を `##` 見出しに変換
- 審査項目見出し（`第〇款` / `第〇項` / ページ行）を `###` 見出しに変換
- 審査項目見出しの折り返し連結処理

## 動作環境

- Python 3.x
- Jupyter Notebook
- 依存ライブラリ：`re`、`pathlib`、`IPython.display`（標準ライブラリのみ）

## 使い方

### 1. リポジトリをクローン

```bash
git clone https://github.com/Sai-Hiromi-eee/Gikai_Gijiroku_Conv.git
cd Gikai_Gijiroku_Conv
```

### 2. Jupyter Notebookを起動

```bash
jupyter notebook
```

### 3. ノートブックを開いてセルを順番に実行

1. **セル①** ライブラリ読み込み（最初に1回）
2. **セル②** `INPUT_DIR` に変換対象フォルダのパスを設定
3. **セル③** 変換コア関数の定義（1回）
4. **セル④** 実行（変換したいときに毎回）
5. **セル⑤** プレビュー（任意）

### 4. 設定例（セル②）

```python
INPUT_DIR  = Path(r'C:\Users\yourname\Documents\gijiroku')
OUTPUT_DIR = None  # Noneの場合はINPUT_DIRと同じ場所に出力
```

## 入出力ファイル形式

### 入力（名取市議会サイトからダウンロードしたTXT）

```
令和７年第４回定例会（第１日目）　本文 2025-09-02.txt
令和７年第４回定例会_第１日目__本文_2025-09-02.txt   ← アップロード時の形式も対応
```

### 出力（Markdown）

```
Cleaned_2025-09-02_令和７年第４回定例会（第１日目）.md
```

## 出力Markdownの構造例

### 本会議版

```markdown
# 2025-09-02_令和７年第４回定例会（第１日目）

## 日程第１　会議録署名議員指名

**議長（○○　○○）**: 日程第１　会議録署名議員の指名を行います。

## 日程第２　議案第○号　令和７年度名取市一般会計補正予算

**市長（○○　○○）**: ただいま上程されました…
```

### 財務常任委員会版

```markdown
# 2025-09-24_令和７年財務常任委員会第３分科会

## 議案第７４号　令和６年度名取市歳入歳出決算の認定について

### 第４款衛生費第１項保健衛生費６目環境衛生費から９目斎場運営費まで

**委員長（○○　○○）**: それでは質疑を行います。

**委員（○○　○○）**: ○○ページについて伺います。
```
